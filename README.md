# SlippiesBot

A Telegram bot that logs and saves expenses straight from a chat message — no app, just send it what you spent.

## What it does

- 💬 **Chat-based expense logging** — no forms, no app, just message the bot
- 🤖 **Gemini API integration** — parses natural language / receipt input into structured expense data
- 📊 **Saves to Excel** — every logged expense gets written to a spreadsheet automatically

## Stack

- Python
- `python-telegram-bot`
- Gemini API
- Excel (openpyxl / similar) for data storage

## Status

Working prototype. V2 is currently in development with expanded features.
